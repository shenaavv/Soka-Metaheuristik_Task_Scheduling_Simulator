The raw trace records normalized CPU and memory demand. It does not contain
lengthMI or absolute RAM, so prepare_google_trace.py maps normalized fields to
the simulator schema:
- lengthMI = round(NrmlTaskCores * 1,000,000), minimum 1
- pes = ceil(NrmlTaskCores * 32), clamped to 1..4
- ramMB = max(1024, round(NrmlTaskMem * 64 * 1024))
- priority = JobType

The generated tasks.csv contains the first 100 unique task IDs with positive
normalized CPU demand from the official trace.
